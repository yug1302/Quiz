# 📝 Quiz Application

A simple and interactive quiz application built using **HTML, CSS, and JavaScript**. The application contains 5 questions and allows users to test their knowledge through an easy-to-use interface.

## 🚀 Features

- **5 Questions:** Answer five questions in a single quiz session.
- **Interactive Interface:** User-friendly design for an engaging experience.
- **Instant Feedback:** Get feedback based on your selected answers. *(If implemented.)*
- **Score Tracking:** Calculate your score based on correct answers. *(If implemented.)*
- **Responsive Design:** Use the application on different screen sizes. *(If implemented.)*

## 🛠️ Technologies Used

- **HTML5** – Structures the quiz interface.
- **CSS3** – Styles the application and improves its appearance.
- **JavaScript** – Handles quiz functionality, answer selection, and score calculation.

## 💻 Getting Started

Follow these steps to run the project on your computer.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual GitHub repository URL.

### 2. Open the Project

Navigate to the project folder:

```bash
cd Quiz-Application
```

### 3. Run the Application

Open the `index.html` file in your web browser.

Alternatively, use the **Live Server** extension in Visual Studio Code to launch the application.

## 🎯 How to Use

1. Open the quiz application in your browser.
2. Read each question carefully.
3. Select your answer from the available options.
4. Complete all five questions.
5. View your score or results if the feature is implemented.
